    Introducción a las Interfaces en Android

    En este tema se abordará el desarrollo de aplicaciones Android y la creación de interfaces de usuario utilizando tanto las técnicas clásicas basadas en XML como la nueva aproximación con Jetpack Compose. Se explorarán los conceptos fundamentales de la interfaz de usuario, incluyendo layouts, controles y adaptadores, así como las ventajas y desventajas de cada enfoque.

    Objetivos

    Los Objetivos de este tema son:

    • Comprender los conceptos básicos de la interfaz de usuario en Android.
    • Aprender a crear interfaces de usuario utilizando layouts y controles clásicos.
    • Explorar el uso de adaptadores para manejar listas y colecciones de datos.
    • Introducir Jetpack Compose como una alternativa moderna para el desarrollo de interfaces de usuario.
